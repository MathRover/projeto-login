# 🔐 Projeto Login

> Página de login simples desenvolvida para fins acadêmicos.  
> **Projeto da faculdade** — nada muito complexo, apenas uma tela de entrada com FAQ.

---

## 📌 O que é?

Uma **página de login** em HTML e CSS que contém:

- **Formulário de entrada** — campo de e-mail, senha e opção “Lembre de mim”
- **Seção de FAQ** — perguntas frequentes que podem ser expandidas (esqueci senha, login não funciona, como criar conta)

O layout usa Bootstrap para deixar tudo organizado e responsivo, e o arquivo `signin.css` cuida do visual do formulário e do bloco de perguntas.

---

## 🚀 Como funciona?

1. Abra o arquivo **`index.html`** no navegador (duplo clique ou arrastando para o Chrome/Edge/Firefox).
2. A tela exibe o formulário de login e, logo abaixo, o FAQ.
3. No FAQ, basta clicar em cada pergunta para abrir ou fechar a resposta.

Não há backend: os dados não são enviados a lugar nenhum. É apenas a **interface** da tela de login, para estudo e demonstração.

---

## 📁 Estrutura

| Arquivo      | Descrição                          |
|-------------|------------------------------------|
| `index.html`| Página principal (formulário + FAQ)|
| `signin.css`| Estilos do formulário e do FAQ     |
